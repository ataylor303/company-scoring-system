# company-scoring-system
A programmed scoring system that evaluates Amazon's performance using weighted business factors.

## Factors 
1. Customer Satifaction 
2. Emplyee Morale
3. Profitability 
4. Revenue Growth 
5. Social Impact

## Weight
1. Customer Satifaction = 40%
2. Emplyee Morale = 20%
3. Profitability = 25%
4. Revenue Growth = 10%
5. Social Impact = 5%

## How it Works
Once the programmed is started the user will be prompted to enter a score for each factor out of 100. 
The user will enter each score and the program will calculate the overall score for Amazon.
